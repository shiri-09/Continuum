≈continuum.A clear path to expression

Four simple steps. The user stays in control.

First, find an input.
Then practise choosing.

01

Set up

The assistant gives spoken instructions. A helper can calibrate camera access or connect a switch.

02

Practise

Choose Yes, then No, while each answer is highlighted. The same movement selects either answer.

03

Personalise

Choose which personal messages to save. A choice never becomes speech automatically.

04

Continue

Talk with the local assistant, compose speech or request a supported computer action.

A suggestion is never permission. Silence is never confirmation.

This is scanning with one selection signal—not a classifier that assigns Yes and No to two different gestures.
